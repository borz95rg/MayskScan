# Maysk Scan

Сканер документов, распознавание текста и PDF-инструменты для Android. **Работает без интернета, бесплатно, без рекламы.**

## Что умеет
- **Сканер документов** — автоматическая обрезка и выравнивание (ML Kit), улучшение качества, фильтры (Ч/Б, контраст, фото, серый), многостраничные сканы → PDF / JPG, PDF с текстовым слоем.
- **Фото → текст (OCR)** — русский, казахский, английский, украинский, немецкий, французский, испанский, турецкий; авто-определение языка; редактирование, поиск/замена, озвучка; экспорт TXT / DOCX / PDF / RTF / HTML / MD / XLSX / CSV.
- **PDF** — просмотр (страница целиком на экране, стрелки и функции сверху, масштаб жестом двумя пальцами, кнопками «+ / −», ползунком и режимами «По ширине» / «Вся страница», поиск, закладки, ночной режим), редактор страниц (порядок, поворот, удаление, вставка, замена), подпись, рисование, текст, водяной знак, печать.
- **Конвертер** — PDF ↔ Word / Excel / PowerPoint / JPG / PNG / TXT, фото → PDF / Word.
- **Сжатие, объединение, разделение, извлечение страниц, защита паролем.**
- **QR и штрихкоды** — сканирование камерой и с фото, создание QR (текст, Wi-Fi, контакт, телефон).
- **Удостоверение / паспорт** — обе стороны на A4 в реальном размере.
- **Пакетная обработка** — десятки фото → один PDF, PDF с текстом или текст.
- **Обрезка листа и выравнивание строк** на обычных фото; **таблицы с фото → Excel по колонкам**.
- **Заполнение PDF-форм**, **разворот книги → 2 страницы**, **Голос → Текст** (диктовка).
- **История и избранное** с поиском по тексту внутри документов, **резервная копия** одним файлом.
- **Блокировка PIN-кодом / отпечатком**, тема и цвет, язык интерфейса (RU/KK/EN), виджет на рабочий стол.
- Открытие файлов из других приложений и единая точка входа «Документы».
- **Офлайн-офис:** OpenDocument.core 7.6.1 визуально открывает и редактирует поддерживаемые DOCX/XLSX/PPTX и ODT/ODS/ODP. Сохранение идёт в исходный формат, а при разрешении SAF — прямо в исходный файл с резервной копией. Старые DOC/XLS/PPT доступны для просмотра.
- **Ввод текста в офисных документах:** в DOCX и PPTX коснитесь существующего текста, поставьте курсор и печатайте; Enter добавляет абзац в текущем текстовом блоке. В XLSX дважды коснитесь ячейки, включая пустую, введите значение и подтвердите Enter. Сохранение — кнопкой облака вверху; если перезапись источника недоступна, выберите отдельную копию. Новые текстовые блоки, таблицы, изображения и слайды без соответствующей команды движка добавить нельзя.
- **Текстовые форматы:** TXT / CSV / MD / HTML / RTF редактируются существующим текстовым редактором.
- **Локальный ИИ:** LiteRT-LM 0.18.1 запускает отдельную модель `.litertlm` на 64-битном ARM-устройстве. Стартовая модель Qwen3-0.6B (~614 МБ, Apache-2.0) скачивается отдельно и импортируется пользователем; документ не отправляется в облако. В текущей версии в контекст попадает до 4 500 символов текста документа; ответ можно скопировать и вручную вставить в редактор, автоматическое применение ИИ-правок будет добавлено отдельно.

Интернет нужен для проверки обновлений, скачивания языковых моделей перевода и (по желанию) отдельной LLM-модели. После загрузки модели ИИ работает офлайн.

## Сборка
Собирается автоматически на GitHub (вкладка **Actions** → «Сборка Maysk Scan»), готовый `MayskScan.apk` — в разделе **Artifacts** запуска. Pull Request в `main`/`master` тоже запускает сборку для проверки; публикация обновления из PR отключена. Языки распознавания скачиваются во время сборки и встраиваются в APK (около 26 МБ данных OCR); офисный движок и локальный AI-runtime дополнительно увеличивают размер APK.

## Секреты репозитория (Settings → Secrets and variables → Actions)
| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | ключ подписи в base64 (выдан отдельно, **в репозиторий не класть**) |
| `KEYSTORE_PASSWORD` | пароль ключа |
| `SUPABASE_SERVICE_KEY` | тот же сервисный ключ, что у Maysk TV — для публикации обновлений |

Без ключа подписи сборка всё равно пройдёт (тестовая подпись), но не будет опубликована как обновление.

## Обновления
После каждой сборки APK выкладывается в `releases/MayskScan.apk` базы Supabase, а номер версии — в `app_settings` (`scan_version_code`, `scan_version_name`, `scan_apk_url`). Приложение показывает карточку «Доступно обновление».

Ссылка для установки: `https://kvzifrdzidubddrwmcmh.supabase.co/storage/v1/object/public/releases/MayskScan.apk`


## Офисный редактор и локальный ИИ (интеграционный этап)

- Android 8.0+ (API 26).
- OpenDocument.core 7.6.1: визуальное открытие и редактирование поддерживаемых DOCX/XLSX/PPTX и ODF-файлов; сохранение в исходный формат, когда формат и SAF-провайдер разрешают запись. Старые DOC/XLS/PPT доступны для просмотра.
- LiteRT-LM 0.18.1: опциональный локальный ИИ. Модель `.litertlm` импортируется отдельно; стартовая модель Qwen3-0.6B (около 614 МБ) не входит в APK.
- Первичный ИИ-контекст ограничен 4 500 символами документа; LiteRT-LM требует arm64-v8a, в 32-битной сборке ИИ отключён. RAG для больших файлов и применение правок ИИ в редакторе — следующие задачи.
- Перед релизом требуется сборка и тест на реальных устройствах; локальная среда этой разработки не содержит Android SDK/Gradle. Подробности: `OFFLINE_OFFICE_ROADMAP.md`.
